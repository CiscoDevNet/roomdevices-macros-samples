# Mute On Entry

![Poster](../Automatic%20Video%20Mute/mute.jpeg)

Scared of appearing non-muted in a large meeting by accident? This simple macro always starts a call with the microphone muted, and also without video if you choose to when installing it.

You can set the number of participants required - eg if you set it to 10, the auto-mute will only occur if more than 10 other participants are already in the call when you join.
